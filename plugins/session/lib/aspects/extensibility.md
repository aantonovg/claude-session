Aspect: extensibility. Read the object for the change that will come next and what it will cost: a fact repeated in several files so the next edit must find all of them, a list one place enumerates and another place assumes, a hard-coded case where the shape asks for a table, a contract stated in prose on one side and in code on the other.

Typical shapes: adding one case means touching five files; a new name must be added to a regex, a doc and a map that nobody links; a default buried in a branch instead of stated once; two sources for one truth, with no check that they agree.

Out of scope: extension points for a case nobody named, plug-in machinery for one implementation, and future work the object's own scope excludes. A hint names the concrete next change and the places it would have to touch.
